# Expo SDK 55 Initialization Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Initialize a clean Expo SDK 55 project using Expo Router, the recommended `src/app` structure, NativeWind, and React Native Reusables.

**Architecture:** Expo Router routes live in `src/app`, with route files kept thin. The home UI lives in `src/screens/home`, reusable UI components live in `src/components/ui`, and shared utilities live in `src/lib`.

**Tech Stack:** Expo SDK 55, Expo Router, React Native, TypeScript, NativeWind, Tailwind CSS, React Native Reusables.

---

## File Structure

- Create or modify root Expo config files: `package.json`, `app.json`, `tsconfig.json`, `metro.config.js`, `babel.config.js`, `tailwind.config.js`, `global.css` or `src/global.css` depending on the NativeWind setup generated by the CLI.
- Create `src/app/_layout.tsx` for the root navigation stack.
- Create `src/app/index.tsx` as a thin route that renders the home screen.
- Create `src/screens/home/index.tsx` for the startup verification UI.
- Create `src/components/ui/button.tsx`, `src/components/ui/card.tsx`, and `src/components/ui/text.tsx` through React Native Reusables.
- Create `src/lib/utils.ts` for `cn`/class merging utilities used by React Native Reusables.
